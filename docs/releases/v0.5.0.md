# mbe-eval v0.5.0

Released: 2026-08-30. The wheel and source archive are attached to the
[GitHub release](https://github.com/AparajeetS/marginal-baseline-eval/releases/tag/v0.5.0).

## Reliability Changes

- separates descriptive `groupby` strata from independent inference units;
- adds cluster-level bootstrap through `inference_unit_col` and
  `--inference-unit`;
- abstains instead of silently reverting to row-level inference when a
  published-study scope has fewer than two declared units;
- makes orthogonal-score inference block-aware;
- preserves existing PyTorch gradients and handles zero-gradient FIM spectra;
- fixes numeric-string selector inputs and per-metric nuisance diagnostics;
- adds scale-invariant numerical rank handling to Functional Influence
  Spectrum; and
- strengthens evidence-table and image-atlas validation.

## Compatibility

Existing calls without `inference_unit_col` retain row-level behavior.
`groupby` has always generated separate strata; documentation now states that
it does not define independent sampling units.
