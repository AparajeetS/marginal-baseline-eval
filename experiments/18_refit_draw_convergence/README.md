# Refit-Draw Convergence

Run the frozen paired Monte Carlo study with:

```bash
python experiments/18_refit_draw_convergence/run_draw_convergence.py \
  --output-dir experiments/18_refit_draw_convergence/out \
  --workers 8
```

See [`PREREGISTRATION.md`](PREREGISTRATION.md) for the claim boundary and fixed
settings.

Completed findings and the operational draw-budget recommendation are in
[`RESULTS.md`](RESULTS.md).
